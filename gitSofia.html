Sessão 2 - Git - repositório

Git

O Git é um sistema de controlo de versões que permite registar as alterações feitas nos ficheiros de um projeto, consultar o seu histórico e colaborar com outras pessoas.

Site oficial do Git.


GitHub

O GitHub é uma plataforma online que permite alojar repositórios Git, partilhar código e colaborar com outros programadores.

Site oficial do GitHub.
